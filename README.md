Production-style E-Commerce Backend built using Java, Spring Boot, PostgreSQL, and REST APIs.

## 🚀 Tech Stack

- Java 17
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven
- Lombok
- Postman
- Git/GitHub
